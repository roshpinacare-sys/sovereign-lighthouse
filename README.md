# 🗼 מגדלור ריבוני — Sovereign Lighthouse

זיכרון חוץ-מכונה עצמאי של מערכת ראש-פינה (T-59). נולד מריפו `sanbox` הפרטי; עץ סטטי זה מוכתב כל עדכון-משמעותי.

## מה יש כאן
- **index.html** — קונסולת-התעוררות (RTL עברית): שכבות-הזיכרון, מצב-הלב, חמשת-צעדי-ההקמה
- **state.json** — תמצית-מצב נטולת-סודות (נסרק אוטומטית לפני כל פרסום)
